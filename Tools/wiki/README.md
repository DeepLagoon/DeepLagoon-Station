# Публикация справочника DeepLagoon

Генератор сохраняет главную «Бортовой справочник», справочные статьи и 16 книг в оформлении «Архив экспедиции». В книге используется бумажная страница внутри тёмной оболочки вики. Карточки предметов, реагентов и рецептов наследуют книжную палитру. Отсутствие рецепта отдельным сообщением не обозначается.

Источники механик: текущие YAML-прототипы, Guidebook XML, FTL-локализация и исходные игровые изображения Station. Существующий русский текст сохраняется; ключевые страницы химика и бармена переработаны. Генерация таблиц не означает ручную проверку каждого абзаца старых переводов. Удалённые прототипы и изображения, которые нельзя разрешить статически, перечисляются в `build-stats.json`.

## Последовательность

1. Создать отдельную папку публикации; получить резервную копию `wiki_api.py snapshot --folder <folder>`. Повторная запись существующей резервной копии запрещена.
2. Выгрузить YAML: `node Tools/wiki/export_prototypes.cjs <station> <folder>/prototypes.json`.
3. Сформировать статьи: `python Tools/wiki/build_reference.py --station <station> --folder <folder> --design Tools/wiki/design`.
4. Преобразовать Markdown: `node Tools/wiki/render_pages.mjs <station> <folder>`.
5. Проверить: `python Tools/wiki/qa_plan.py <folder>` и `python Tools/wiki/test_reference.py`.
6. Загрузить изображения: `python Tools/wiki/wiki_api.py assets --folder <folder>`.
7. Обновить статьи: `python Tools/wiki/wiki_api.py apply --folder <folder>`. Для проверки нескольких страниц — `--only home,guidebook/in_game/books/bartenders-manual`.
8. Проверить сохранённый текст и публичные адреса: `python Tools/wiki/verify_publication.py <folder>`; визуальная проверка — `node Tools/wiki/verify_live.cjs <folder>`.

API-ключ читается исключительно из переменной окружения `DEEPLAGOON_WIKI_TOKEN`. Не записывайте его в исходники, конфиги или отчёты. Библиотеки: Python PyYAML; Node js-yaml, marked и Playwright. Утверждённый дизайн сохранён в `Tools/wiki/design`: папка с `theme.css`, `home-features.css`, `wikijs/a-home.html`, `wikijs/a-guide.html`, `asset-credits.json`.

`before/` содержит исходные страницы с редактором, тегами, приватностью и CSS. `publication.json` фиксирует исходный план и фактически сохранённое состояние: Wiki.js минифицирует CSS. Изменённые после снимка страницы не перезаписываются; то же правило действует для ранее созданных генератором страниц. Неизвестный результат сетевой мутации требует чтения состояния перед повтором. Резервные копии позволяют восстановить нужную страницу через `pages.update` и вернуть прежний редактор через `pages.convert`.

`wiki.routes.txt` содержит 521 привязку; `wiki.toml` — готовый блок настроек. Книги получают отдельные книжные адреса. Корень встроенного дерева — `/ru/guidebook/in_game`. Файл-пресет сам по себе не меняет работающий сервер: перенесите значения в выбранный слот Control и примените штатным способом.

Рецепты формируются заново при запуске генератора. Фоновой синхронизации с репозиторием нет. Для проверки механики в клиенте отдельно нужны установленная сборка и игровой сеанс.

Значок вкладки устанавливается отдельно: `python Tools/wiki/set_favicon.py <favicon-256.png> --folder <folder>`. Скрипт сохраняет прежние настройки темы, публикует файл с уникальным именем и добавляет только ссылки favicon в HTML head. Логотип шапки не меняется.

Для favicon рядом с `favicon-256.png` нужны `favicon-16.png`, `favicon-32.png`, `favicon-192.png`. Воспроизводимая обтравка исходного изображения сохранена в `design/favicon/Cutout.cs`; готовая прозрачная эмблема — `design/favicon/deeplagoon-transparent.png`.

Редакционные исключения для отдельной статьи задаются в `article_filters.py`: в `chemicals` скрыты обе карточки Проктосилина, удалены приписки «(рост)» и «(уменьшение)», счётчики групп корректируются автоматически. Игровые прототипы не меняются.
