# Псионика и настроение Einstein Engines в DeepLagoon

Источник: локальный архив `D:\Downloads\Einstein-Engines-master\Einstein-Engines-master`.
Код и ресурсы адаптированы к текущей базе DeepLagoon; тексты лицензий upstream и
метаданные двух объединённых RSI сохранены рядом с этим документом. Метаданные
новых RSI и звуков сохранены с ресурсами.

## Игровая интеграция

- Базовые гуманоиды получают настроение и латентную псионику.
  шанс пробуждения 1% через 30 секунд; стартовая попытка выдаёт максимум одну силу.
  Реагенты и события используют накопление потенции и повторные броски. Для существ и аномалий восстановлены связанные
  псионические компоненты; синтетики получают изоляцию.
- Перенесены способности, фамильяры, телепатический чат (`=` или `tsay`),
  глиммер, установки, реестр псиоников, картридж монитора и события глиммера.
  Телепатия доступна в нативном и TGUI-чате. Псионические материалы и предметы
  доступны по их прототипам, установки имеют строительные графы.
- Реестр использует доступ DeepLagoon: Chapel, Research или ResearchDirector.
  События подключены к BasicGameRulesTable и учитывают пороги глиммера.
- Настроение реагирует на здоровье, голод, жажду, огонь, удушье, давление,
  наручники, скольжение, рвоту, кремовый пирог, объятия, животных, благословение,
  аркады, роль предателя и реагенты. Влияет на скорость, насыщенность изображения
  и силу псионики; эффекты можно просмотреть через индикатор настроения.
- Повторный эффект продлевает таймер без суммирования; потребности одной категории
  заменяют друг друга. Снятие экипировки сохраняет врождённые способности.
- Расширенная система черт EE перенесена отдельно: см.
  [черты](../Einstein-Engines-Traits/README.md). Отдельные профессии,
  големоведение и вид Shadowkin не мигрируются. Используется только фазовое состояние для псионических
  способностей. Размещение новых объектов на картах не менялось.
- Использованы доступные переводы из архива EE. Для отсутствующих русских
  описаний используется английский текст upstream.

## Настройки

| CVar | По умолчанию | Назначение |
| --- | --- | --- |
| `mood.enabled` | true | Настроение; переключение очищает или восстанавливает эффекты |
| `mood.increases_speed` | true | Ускорение при хорошем настроении |
| `mood.decreases_speed` | true | Замедление при плохом настроении |
| `mood.modify_thresholds` | false | Изменение порога критического состояния |
| `mood.visual_effects` | true | Клиентская насыщенность изображения |
| `psionics.roundstart_chance` | 0.01 | Шанс стартового получения одной силы; 0 отключает, 1 гарантирует |
| `psionics.rolls_enabled` | true | Случайное получение способностей |
| `glimmer.enabled` | true | Глиммер и связанные события |
| `psionics.scarier_mindbreaking` | false | Изгнание игрока из тела при разрушении разума |

## Проверка

`Content.IntegrationTests/Tests/_DeepLagoon/PsionicsMoodTests.cs` проверяет эффекты
настроения, выдачу и снятие сил, экипировку, создание объектов, инициализацию всех
псионических сил, применение ноосферного разряда (луч и паралич цели),
ограничение стартового пробуждения без ограничения последующих попыток,
химические реакции масла и нормалити-кристаллов, содержимое чаши OusianaDust
и валидацию перенесённых прототипов на сервере. Клиентская
загрузка также выполняется в тестовой паре.

Сборка при запущенном локальном сервере выполняется в отдельный каталог:

```powershell
dotnet build Content.IntegrationTests/Content.IntegrationTests.csproj --no-restore -p:BuildTgui=false -p:OutputPath=C:\old_disk\repos\DeepLagoon-Station\bin\PsionicsTests\
dotnet vstest bin/PsionicsTests/Content.IntegrationTests.dll /TestCaseFilter:FullyQualifiedName~PsionicsMoodTests
```

Ручной игровой прогон: пробудить персонажа, проверить кнопки и телепатию,
использовать способности, надеть/снять изоляцию и псионические предметы,
изменить голод/здоровье/настроение, посмотреть индикатор и насыщенность,
проверить установки, картридж и реестр на карте станции.

## Получение реагентов

- `LotophagoiOil`: 1 SpaceDrugs + 1 Cognizine → 1 масла; минимум 5 Plasma как
  катализатор, плазма не расходуется. Активирован закомментированный рецепт EE.
  Cognizine варится по существующему рецепту DeepLagoon.
- Нормалити-кристалл: по 5 Ash, Water, Blood и Ectoplasm, плюс 5 Plasma как
  катализатор; нагрев минимум до 400 K. Выход — `MaterialNormality1`.
- `OusianaDust`: через меню строительства, 1 Bluespace + 1 Normality + большая
  миска. Чаша `FoodOusianaDustBowl` содержит 5 единиц порошка, как в EE.
- Для Ectoplasm, SoulbreakerToxin и PsionicRegenerationEssence новые химические
  рецепты не вводились: в архиве EE их нет.
